# Bank Application Project

A simple banking application built using Java and SQL.  
This project includes basic banking functionalities:

- Create new accounts
- Check balance
- Transaction history
- Data storage using SQL (MySQL)
- OOP structure: Account class, Customer class, BankService

## Technologies Used
- Java (OOP basics)
- SQL (SELECT, JOIN, WHERE)
- Maven
- JavaFX for GUI (if applicable)
